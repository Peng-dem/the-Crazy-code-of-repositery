# 各平台价格字段识别指南

按图片来源平台定位"实付"字段。识别时以图中实际文字为准，本指南仅提供常见 UI 模式参考。

## 淘宝 / 天猫

**订单详情页**（最常见）：
- 顶部订单状态区：「实付款 ¥xx.xx」（大字，通常为橙色/红色）
- 金额明细区：「商品金额」「运费」「优惠」分项列出
- 若有「价保」或「退差价」提示，注意金额可能是"预估可退"

**订单列表页**：每个订单卡片底部显示「实付 ¥xx」；状态为"退款成功"的订单，该金额是原实付金额

**商品详情页**：「¥xx」为当前售价，划线灰字为原价，「券后 ¥xx」为领券预估价 —— 均非实付价

## 京东

**订单详情页**：
- 「实付款」字段常在订单信息区，京东习惯把「商品总额」「运费」「优惠」放在"金额明细"折叠区
- 京东自营常见「plus 会员价」「秒杀价」等标价，均为售价非实付

**支付成功页**：跳转支付宝/微信支付凭证，看支付凭证大字金额

**订单列表**：卡片上金额默认为实付金额（含运费）

## 拼多多

- 「实付金额」字段在订单详情中上部；拼多多大量使用「单独购买价」「拼单价格」，两者都不是实付价
- 「免单」「返现」活动：实付价以支付凭证为准，返现是后续到账，不冲减当时实付
- 砍价免费拿页面：显示 ¥0.00 是目标价，不是实付

## 抖音电商 / 快手

- 订单详情「实付金额」；直播间的「秒杀价」「直播间专属价」为售价
- 注意「赠送运费险」「平台补贴」标签，补贴有时直接减实付，有时是红包形式（不冲减实付）

## 美团 / 饿了么（外卖与团购）

**外卖订单**：
- 「实付款」在订单详情底部费用明细区：餐品费 + 打包费 + 配送费 − 红包/优惠券 − 会员折扣 = 实付款
- 「商家代金券」「红包」分属不同减免，校验时全部计入优惠侧

**团购/到店券**：支付成功页的「支付金额」为实付；「价值 ¥xx」为门市价非实付

## 支付宝支付凭证

- 中央大号金额即实付；下方「付款方式」「商户全称」「订单号」
- 「优惠券」「立减」等明细行是已抵扣说明，不要再从大字金额中减一次
- 退款凭证：「退款金额」≠ 支付金额，注意方向

## 微信支付凭证

- 「支付金额」大字为实付；「当前状态：支付成功」确认有效
- 转账记录：「转账金额」即实际支出；若显示"已退还"则最终支出为 0

## 纸质小票 / 收据

- 「合计」「实收」「应付金额」「TOTAL」为实付
- 「会员价」「原价」不作实付；「优惠/折扣」行计入校验公式
- 手写收据注意：大小写金额不一致时以大写（壹贰叁…）为准，并向用户指出不一致

## 通用校验公式

```
实付款 = Σ(商品单价 × 数量) + 运费 + 打包费 − 优惠券 − 红包 − 积分抵扣 − 会员折扣
```

误差必须为 0（分位）；若差 1~2 元级差额，通常是「部分退款」或「价保退差」，需在输出中说明。

## 易错陷阱速查

| 陷阱 | 特征 |
|------|------|
| 划线价 | 带删除线或灰色小字的"原价" |
| "xx起" | 列表页最低规格价，非所选商品价 |
| 定金/尾款 | 定金 + 尾款之和才是实付，页面上常只显示其一 |
| 预售膨胀金 | "定金xx抵xx"，实付仍按定金+尾款计 |
| 运费险 | 几元保费已计入实付，不是优惠 |
| 合并支付 | 一次支付多订单时，支付凭证金额是总额，需分单核对 |
| 积分抵扣 | 虚拟抵扣不改变实际现金流口径时，按平台标注的"实付"为准 |
